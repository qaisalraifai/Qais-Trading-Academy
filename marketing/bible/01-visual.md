## ٢ · الإضاءة

الفضاء **جوّ** مش موضوع. القاعدة: **الضوء بيجي من الحواف والعمق، مش من مصادر ظاهرة**.

```
سديم بنفسجي     radial-gradient(60% 40% at 22% 12%, rgba(124,77,255,.30), transparent 62%)
سديم سماوي      radial-gradient(55% 38% at 82% 84%, rgba(34,211,238,.16), transparent 60%)
توهّج عنصر       0 0 34px -8px rgba(124,77,255,.45)     ← shadow-glow-violet
لمعة حافة        inset 0 1px 0 rgba(255,255,255,.055)   ← shadow-edge
عمق              0 18px 40px -18px rgba(0,0,0,.75)      ← shadow-module
```

⚠️ **التوهّج محسوب**: قيمة سالبة بالانتشار (`-8px`) فبيضل ملاصقاً للعنصر. توهّج بلا حدّ = مظهر رخيص.

⚠️ **ولا مصدر ضوء ظاهر** — ولا شمس، ولا كوكب، ولا عدسة flare.

### النجوم

```
العدد        ~٣٠٠ على إطار 1080×1920
الحجم        0.4–1.5px عادي · 1.6–3.7px للمضيء (٦٪)
الشفافية     0.10–0.42 عادي · 0.50–0.90 للمضيء
اللون        ٨٧٪ أبيض مائل #E2DEFF · ١٣٪ بنفسجي أو سماوي
هالة         للمضيء وبس — نفس اللون بشفافية ×0.13 ونصف قطر ×3.4
```

🔴 **بذرة ثابتة إلزامية.** بلاها كل تشغيل بيعطي نجوماً مختلفة — فما بتقدر تصلّح مشهداً بلا ما يتغيّر باقي الفيديو، ولا تركّب لقطتين مع بعض.

## ٣ · الطباعة

```
الواجهة    IBM Plex Sans Arabic   ← عربي ولاتيني من نفس العائلة
العرض      Archivo                ← اللاتيني الكبير والأرقام
الأحادي    IBM Plex Mono          ← الرموز والمعرّفات (⚠️ ما فيه عربي)
```

### السلّم على إطار 1080×1920

```
h1        104px / 700 / line-height 1.15 / tracking -0.02em
h2         80px / 700 / 1.28  / -0.015em
h3         64px / 700 / 1.35  / -0.01em
lead       56px / 500 / 1.5   / text-secondary
cap        40px / 500 / 1.6   / text-muted
eyebrow    34px / 600 / letter-spacing 0.06em / violet-100
disclaimer 27px / 400 / 1.75  / #8A82AE
```

### 🔴 ثلاث قواعد عربية بتنكسر إذا انتُهكت

**١ · ممنوع `letter-spacing` على العربي.** الحروف العربية **متّصلة** — التباعد بيفكّها لحروف مقطّعة. `tracking: 0.28em` على «الأدوات» بتطلع «ا ل أ د و ا ت» مكسورة.

**٢ · ممنوع `font-mono` على العربي.** IBM Plex Mono ما فيه محارف عربية → بيقع على خط النظام الاحتياطي، فبيبان غريباً عن باقي الإطار.

**٣ · `uppercase` بلا معنى** بالعربي — ما في حالة أحرف.

⚠️ فالـ`eyebrow` بيتنسّق **بطريقتين**: لاتيني بـmono + uppercase + tracking، وعربي بخط الواجهة بلا تباعد.

### حدود النص

```
سطر واحد   ≤ ٢٨ حرفاً عربياً
الإطار      ≤ ٣ أسطر بأي لحظة
⚠️ المشاهد بيقرا وهو ماشي — نص أطول = تمرير
```

## ٤ · الهندسة

🔴 **الحواف قائمة.** `borderRadius.DEFAULT = 3px` بنظام ORBIT، والقاعدة المكتوبة: «الانحناء بس للعناصر الصغيرة اللمسية».

```
البطاقات والأطر    2–4px
الأزرار            4px
الحبوب (pills)     999px  ← للشارات الصغيرة وبس
```

⚠️ **هاي بالذات اللي بتفرّقك عن قوالب SaaS.** كل قالب بالسوق `rounded-2xl`. الحدّة الهندسية هي التوقيع.

## ٥ · معالجة واجهة المنصّة

🔴 **قاعدة مطلقة: الواجهة الحقيقية وبس.**

```
✅ لقطة من المنصّة الشغّالة        ✅ نفس ألوان الواجهة كما هي
✅ نفس البيانات المعروضة          ✅ نفس الخطوط
❌ داشبورد مرسوم للفيديو          ❌ ميزة مش موجودة
❌ إعادة تلوين الواجهة            ❌ سلوك شارت غير واقعي
```

**الطريقة:** الواجهة الحقيقية بتنحطّ **جوّا بيئة سينمائية** — مش بتنعاد رسمها.

```
الإطار      حدّ 1px edge + shadow-module
الأرضية     space-0 مع سديم خفيف
العمق       إمالة طفيفة ≤ ٦° + parallax عند الحركة
الإضاءة     توهّج بنفسجي من تحت الإطار وبس
```

## ٦ · المناطق الآمنة (9:16 · 1080×1920)

```
┌─────────────────────────┐  0
│   ⚠️ منطقة الواجهة       │  ← أول ١٨٠px: أيقونات التطبيق
├─────────────────────────┤  180
│                         │
│      منطقة آمنة          │  ← النص والعناصر المهمة هون
│      180 → 1620         │
│                         │
├─────────────────────────┤  1620
│   ⚠️ منطقة الواجهة       │  ← آخر ٣٠٠px: اسم الحساب والوصف

```

⚠️ **الأسفل أخطر** — تيك توك وريلز بيحطّوا اسم الحساب والوصف والأزرار هناك. إخلاء المسؤولية عند `bottom: 150px` بيقع **فوق** المنطقة المغطّاة.

⚠️ **المركز البصري عند ٤٥٪ مش ٥٠٪** — العين بتقع أعلى من المنتصف على الشاشة العمودية.

## ٧ · التعرّف على العلامة بلا شعار

المشاهد لازم يعرف إنه QTA من **خمسة** بلا ما يشوف الشعار:

```
١  الأسود البنفسجي العميق (#050308) مع سديم بنفسجي/سماوي
٢  الحواف القائمة ٢–٤px — ولا انحناء كبير
٣  منحنى الحركة cubic-bezier(.16, 1, .3, 1) — دخول سريع، استقرار طويل
٤  حقل نجوم خافت بعمق حقيقي
٥  IBM Plex Sans Arabic بأوزان ٦٠٠–٧٠٠
```

⚠️ الشعار بيظهر **بآخر ثانيتين وبس**. حطّه بالأول = خسارة الخطّاف؛ الناس ما بتعرفك بعد.
