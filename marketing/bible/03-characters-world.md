# الجزء الأول — الشخصيات

## 🔴 القاعدة الحاكمة

**الشخصيات مش أدوات لقول نص تعليمي.**

ريان **مش روبوت بيعرف كل شي**، وآدم **مش غبي**. لو صار ريان يجاوب صح ١٠٠٪ من المرات، بيصير محاضرة بأفواه — والمشاهد بيوقف يرتبط.

⚠️ **ريان بيغلط كمان** (حلقات ٢٩ · ٤٠ · ٤٧). وأحياناً **آدم بيكون محقّاً** وريان بيتراجع. هاد اللي بيخلّي العلاقة حقيقية.

## آدم — البطل

```
العمر         ٢٤–٢٧
الخلفية       تعلّم من محتوى مجاني · حساب حقيقي صغير · نتائج متذبذبة
الوظيفة       المشاهد نفسه. كل غلطة بيعملها آدم عملها المشاهد.
```

**الشخصية**

```
ذكي بس متسرّع            بيفهم بسرعة وبينفّذ أسرع
بيتأثر بالحركة            الشمعة الكبيرة بتحرّكه قبل ما يفكّر
صادق مع حاله             بيعترف بغلطه — بعد ما يتعصّب شوي
عنده كبرياء               ما بيحب يسمع «قلتلك»
بيتطوّر ببطء             ⚠️ مش بحلقة — بموسم
```

**المظهر** — هودي داكن `#141024` · شعر قصير مبعثر · بلا لحية أو خفيفة · عيون واسعة بتتحرّك بسرعة.

**لغة الجسد**

```
راحة      متكئ لورا، يد على الماوس
توتّر     مايل لقدّام، وجهه قريب من الشاشة
FOMO      واقف · اليد على الكيبورد قبل ما يقرّر
خسارة     مسنود لورا، إيده على راسه
إدراك     بيتجمّد. ⚠️ هاي اللحظة — سكون تام.
```

**الصوت** — أردني شبابي، سريع، بيقاطع، بيرفع صوته لما يتحمّس.

**قوس الموسم**

```
١–١٠     الفوضى        FOMO · انتقام · بلا خطة
١١–٢٠    الوعي         بيشوف النمط بس ما بيقدر يوقفه
٢١–٣٠    الأدوات       Replay · Journal · Backtest
٣١–٤٠    الانضباط      بيلتزم — وبيخسر وبيضل ملتزم
٤١–٤٨    الاتساق       بيصير هو اللي بيسأل الأسئلة الصح
```

⚠️ **ولا قفزة**. آدم بالحلقة ٤٠ لسا بيغلط — بس **غلطات أذكى**.

## ريان — المرشد

```
العمر         ٣٢–٣٦
الخلفية       متداول بيشتغل بعملية · مرّ بنفس الفوضى وطلع منها
الوظيفة       بيعلّم بالسؤال مش بالجواب.
```

**الشخصية**

```
هادي بلا برود           بيهتم فعلاً بآدم
بيسأل بدل ما يجاوب      «شو خطّتك؟» بدل «لا تدخل»
ما بيعطي إشارات         🔴 قاعدة صلبة — شوف تحت
بيضحك                   ساخر خفيف، مش متعالي
بيعترف بجهله            «ما بعرف. خلينا نختبرها.»
```

**المظهر** — قميص بسيط داكن · شعر مرتّب · لحية قصيرة · حركة قليلة ومحسوبة.

**لغة الجسد** — ثابت غالباً. **إشارة وحدة بالحلقة كحد أقصى** — فلما يتحرّك، بيلفت النظر.

**الصوت** — أبطأ من آدم، جمل قصيرة، بيسكت قبل الجملة المهمّة.

### 🔴 قاعدة ريان الحديدية

**ريان ما بيقول «ادخل» ولا «اطلع» ولا «هالصفقة رابحة» — ولا مرة.**

```
❌ «ادخل هون»           ✅ «شو اللي بيخلّيك تدخل هون؟»
❌ «هاد رح يطلع»        ✅ «شو سيناريوهاتك لو نزل؟»
❌ «أنا دخلت»           ✅ «شو بتشوف بالهيكل؟»
```

⚠️ **مش تفصيلاً أسلوبياً — هو حماية قانونية.** شروط منصّتك بتقول «لا نقدّم توصيات أو إشارات تداول». شخصية بتعطي إشارات بتناقض شروطك المنشورة.

## الشخصيات الرمزية

⚠️ **بتظهر كـ«حضور» مش كشخصيات كرتونية.** ولا وجوه، ولا أذرع، ولا كلام مباشر.

```
FOMO       ⚠️ الوحيد المعتمد للموسم الأول
           هالة بنفسجية بتزحف من طرف الإطار وبتشدّ العين للشمعة.
           بتختفي لحظة ما آدم يفكّر.
           بتظهر بالحلقات: ١ · ٦ · ٢٣ · ٣١

GREED      توهّج بيزيد حول رقم الربح لما آدم يقرّر يستنى أكتر.
FEAR       الإطار بيضيق (vignette) قبل ما يسكّر مبكراً.
REVENGE    اهتزاز خفيف جداً بالواجهة بعد خسارة.
```

🔴 **ولا شخصية رمزية بتحكي.** ثانية ما تحكي، بتصير كرتوناً رخيصاً — وهاد بقائمة ممنوعاتك حرفياً.

# الجزء الثاني — العالم

## المكان

**مكان واحد ثابت للموسم الأول: غرفة آدم.**

⚠️ مكان واحد = تعرّف فوري + إنتاج أرخص + المشاهد بيركّز على الحوار مش على البيئة.

```
الحجم      غرفة صغيرة — مش مكتب شركة
الوقت      ليل غالباً · نهار للحلقات الهادية
النافذة    ورا آدم · مدينة بعيدة خارج التركيز
```

## الإضاءة

```
مفتاح       من الشاشة على وجه آدم — بنفسجي مائل
حافة        سماوي خفيف من اليسار، بيفصله عن الخلفية
محيط        ≤ ١٥٪ — الغرفة معتمة
```

⚠️ **ولا مصباح سقف.** الضوء من الشاشات وبس — هاد اللي بيربط العالم بهوية المنصّة.

## الشاشات

🔴 **الشاشات بتعرض واجهة QTA الحقيقية. ولا داشبورد مرسوم.**

```
شاشة رئيسية    الشارت (Replay أو الرادار)
شاشة جانبية    السجل أو التقارير
هاتف           للإشعارات — الملهي
```

⚠️ **الشاشة عنصر سردي مش ديكور**: لما ينفتح الشارت، الكاميرا بتدخل جوّاه ويصير هو المشهد.

## غياب ريان

⚠️ ريان **مش بالغرفة غالباً** — بيظهر بمكالمة، أو شاشة مشاركة، أو بيدخل لثواني.

```
السبب ١   غيابه بيخلّي حضوره مهماً
السبب ٢   بيخلّي آدم يواجه قراره لحاله — وهاد جوهر القصة
السبب ٣   إنتاج أخف
```

## القاعدة الزمنية

**كل حلقة لحظة واحدة.** ولا انتقال زمني جوّا الحلقة إلا لـ`Replay` — وهاي **ميزة بالمنتج** فبتنعرض كواجهة حقيقية.

## ظهور QTA بالعالم

```
✅ الشارت اللي بيشتغل عليه آدم        ✅ زر القص لما ريان يقول «رجّعها»
✅ السجل لما يراجعوا                  ✅ الرادار لما يجي ذكر الفرص
❌ شعار طاير بالغرفة                  ❌ شخصية بتقول اسم المنصّة
❌ ملصق على الحيط                     ❌ إعلان جوّا القصة
```

🔴 **المنصّة تظهر لأنها أداة الشخصية، مش لأنها راعي الحلقة.**
