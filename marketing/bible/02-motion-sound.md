# QTA MOTION & SOUND BIBLE

كل حركة إلها **سبب**. الحركة بلا وظيفة بتخفّض الإحساس بالجودة بدل ما ترفعه.

---

## ١ · منحنيات الحركة

من `tailwind.config.js` حرفياً:

```
orbit    cubic-bezier(0.16, 1, 0.3, 1)     ⭐ الافتراضي — دخول سريع، استقرار طويل
enter    cubic-bezier(0.05, 0.7, 0.1, 1)   دخول عنصر
exit     cubic-bezier(0.3, 0, 0.8, 0.15)   خروج عنصر
```

### المدد

```
fast    140ms   تغيّر لون · حالة زر
base    220ms   ظهور عنصر · تبديل
slow    380ms   انتقال بطاقة · توهّج
orbit   600ms   حركة كاميرا · كشف مشهد
```

🔴 **`orbit` هو التوقيع الحركي.** الدخول السريع + الاستقرار الطويل بيعطي إحساس «آلة دقيقة بتستقر» مش «عنصر بينط». استعمل غيره **وبس** لما يكون في سبب.

---

## ٢ · لغة الكاميرا

خمس حركات معتمدة. **ولا وحدة غيرهن.**

```
DRIFT      زحف بطيء 2–4% على ٦–١٠ ثواني
           للمشاهد الساكنة — بتمنع «الصورة الميتة»

PUSH IN    تقريب 8–15% على ٨٠٠–١٢٠٠ms
           عند لحظة إدراك أو قرار

PULL BACK  تبعيد بيكشف السياق
           ⚠️ الأقوى بالمنصّة: «شفت شمعة؟ خليني أوريك السياق كله»

PARALLAX   الطبقات بتتحرّك بسرعات مختلفة (نجوم 0.3× · محتوى 1×)
           للعمق عند التمرير الجانبي

HOLD       سكون تام
           ⚠️ مقصود: بعد لحظة قوية، السكون بيخلّيها تترسّب
```

### ممنوع

```
❌ دوران الكاميرا (roll)      ❌ اهتزاز
❌ zoom سريع مفاجئ           ❌ حركة بلا سبب سردي
❌ أكتر من حركتين بنفس اللقطة
```

## ٣ · الانتقالات

```
CUT             القطع المباشر — الافتراضي، ٨٠٪ من الانتقالات
MATCH CUT       شكل بينتقل لشكل مشابه (شمعة → عمود بيانات)
LIGHT SWEEP     خط ضوء بيمسح الإطار (300ms) — بين قسمين
WHIP            ⚠️ نادر: عند تغيّر إيقاع حاد وبس
DISSOLVE        ⚠️ ممنوع إلا لمرور الوقت
```

⚠️ **القطع المباشر هو الأصل.** الانتقالات المزخرفة بتقول «قالب».

```
توهّج بنفسجي يزيد       العنصر صار نشطاً أو مهماً

```

## ٥ · 🔴 قاعدة زمن القراءة — الأهم بالوثيقة كلها

**هاي القاعدة انكتبت بعد فشل مقيس.** أول تلات ريلز انتجن، وحكمه: «كثير سريع، مش مفهوم إشي». القياس أكّد إنه محقّ — **كل نص فيهن** كان أسرع من قدرة القراءة:

```
النص                                    كلمات  ظاهر   لازم
بطاقة أداة (عنوان + وصف)                  ٧    ٠.٦ث   ٤.١ث   ← أسرع ٦.٦×
«01 منهج مرتّب — ست ركائز بالتسلسل»       ٦    ٠.٨ث   ٣.٦ث   ← أسرع ٤.٥×
«ترتيب: تبدأ من وين وتنتهي وين»           ٦    ١.٢ث   ٣.٦ث   ← أسرع ٣×
«ولسا بتفتح الشارت وما بتعرف تبلّش؟»       ٩    ٢.٤ث   ٥.١ث   ← أسرع ٢×
```

### المعادلة

```
الزمن اللازم (ثانية) = 0.6 + (عدد الكلمات ÷ 2)
```

`0.6` = زمن ملاحظة إنّ عنصراً ظهر. `÷2` = القراءة على شاشة متحرّكة ≈ **كلمتان بالثانية** (أبطأ من قراءة الورق لأنّ العين بتتابع حركة كمان).

```
٣ كلمات → ٢.١ث     ٦ كلمات → ٣.٦ث     ٩ كلمات → ٥.١ث
```

⚠️ **والحد الأدنى ٢.٠ث** مهما كان النص قصيراً — أقل من هيك المشاهد ما بيلحق يحوّل نظره.

### القواعد المشتقّة

```
١  ولا نص بيظهر أقل من زمنه المحسوب — بلا استثناء
٢  الفاصل بين عنصرين ≥ زمن الأول
٣  ≤ ٥ كلمات بالبيت الواحد
   ⚠️ أطول من هيك: قسّمه لبيتين، لا تسرّعه
٤  كلمة كبيرة + سطر صغير تحتها  ←  أفضل من جملة كاملة
   «ترتيب» + «تبدأ من وين» بتقرأ أسرع من «ترتيب: تبدأ من وين وتنتهي وين»
```

### 🔴 المقايضة المحسومة

**لما ما يكفي الوقت: اقطع محتوى، لا تسرّع.**

فيديو ٢٢ ثانية بستّ أفكار **مش مفهوم**. نفس الفيديو بتلات أفكار **بيوصل**. والفيديو الأطول المفهوم بيتفوّق على الأقصر غير المفهوم — لأنّ اللي ما انفهم ما بينشارك ولا بينحفظ.

⚠️ **ريلز وتيك توك بيسمحوا لـ٩٠ ثانية.** ٣٠–٣٥ ثانية مفهومة أفضل بكتير من ٢٢ مضغوطة.

## ٦ · 🔴 فخّ `fadeOut ... both` — عطل مقيس

عنصر إله حركتان على نفس الخاصية:

```css
/* ✗ غلط — كل السطور بتبان من أول الفيديو */
animation: riseIn .7s 15.2s both, fadeOut .5s 19.0s both;

/* ✓ صح */
animation: riseIn .7s 15.2s both, fadeOut .5s 19.0s forwards;
```

**السبب:** `both` = تعبئة أمامية **ورجعية**. فـ`fadeOut` قبل ما تبلّش بتطبّق `from{opacity:1}` — وهي **آخر وحدة بقائمة الحركات فبتغلب**. النتيجة: العنصر ظاهر من الثانية صفر بدل ما يستنى دوره.

⚠️ **مقيس بالحلقة ٠١**: أربع سطور حوار انطبعوا فوق بعض بنفس الإطار، واسم «ريان» ظهر مرتين. مسحت كل الملفات ولقيت **٩ حالات**.

**القاعدة:** حركة الظهور تاخد `both`، وحركة الاختفاء تاخد `forwards` — بلا استثناء.

## ٧ · إيقاع الريل

```
0.0 – 0.8s    الخطّاف — عنصر واحد وبس
              🔴 أهم ٨٠٠ms بالفيديو كله
0.8 – 3.0s    التوتر
3.0 – X       الجسم — عنصر جديد كل 0.6–0.9s
آخر 3s        الحسم + الشعار
آخر 1.5s      إخلاء المسؤولية
```

⚠️ **ولا عنصرين بيدخلوا بنفس اللحظة.** التداخل بيشتّت العين.

⚠️ **بعد كل لحظة قوية: سكون 400–600ms.** هاد اللي بيفرّق «سينمائي» عن «مونتاج سريع».

## ٦ · الصوت

### الهوية الصوتية

```
الأرضية       طبقة فضائية عميقة 40–80Hz — مستمرة، بالكاد مسموعة
الواجهة       نقرات رقمية قصيرة (20–40ms) عند ظهور عنصر
الانتقال      whoosh خفيف 200–300ms
التأكيد       ضربة منخفضة (low impact) عند لحظة الحسم
النهاية       رنين بنفسجي هادي مع الشعار
```

### المسلسل — طبقات إضافية

```
غرفة          صدى خفيف جداً · إحساس مساحة مغلقة
كيبورد        عند كتابة آدم
ماوس          نقرة عند الضغط
إشعار         نغمة قصيرة عند حركة السوق
موسيقى        هادية تحت الحوار · بتوقف عند لحظة الإدراك
```

🔴 **السكون أداة.** قبل جملة ريان الحاسمة: **قطع كل الصوت 300ms**. بيشتغل أقوى من أي مؤثّر.

### ممنوع

```
❌ أصوات كرتونية (boing · pop مبالغ)
❌ موسيقى تحفيزية صاعدة (كليشيه المؤثّرين)
❌ صوت كاش أو عملات
❌ صوت أعلى من الحوار
```

### 🔴 قاعدة النشر

**ارفع الفيديو بلا صوت وحطّ الموسيقى من داخل التطبيق.**

```
السبب ١   مقاطع إنستغرام/تيك توك مرخَّصة — ولا مطالبة حقوق
السبب ٢   الخوارزمية بتفضّل الصوت الداخلي → وصول أعلى
```

⚠️ **الاستثناء الوحيد: صوتك انت.** تعليق بصوتك أقوى من أي موسيقى — الناس بتشتري من شخص مش من شعار. ولو سجّلته، بينركّب على الفيديو بأمر واحد.
