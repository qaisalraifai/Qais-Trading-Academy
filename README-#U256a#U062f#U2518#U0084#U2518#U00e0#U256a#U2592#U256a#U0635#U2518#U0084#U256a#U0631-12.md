# المرحلة 12 — الدردشة (جاهزة)

## شو رح يتغيّر
- كل دفعة إلها غرفة دردشة خاصة فيها بس، ما في أي اختلاط بين دفعتين.
- الطالب بيشوف الدردشة بصفحة الدورة عنده (تحت مكتبة الملفات)، ويقدر يكتب ويشوف ردود
  زملائه ومدربه.
- المدرب/الأدمن بيقدر يفتح دردشة أي دفعة من لوحة التحكم ويرسل فيها مباشرة.
- الرسائل بتتحدّث تلقائيًا كل 3 ثواني عند الطرفين (طالب وأدمن) بدون أي تحديث للصفحة —
  استقصاء دوري خفيف بدل Realtime، بما إنه ما في RLS مفعّل على جداول الدفعات أصلاً
  بمشروعك (كل الحماية حاليًا عن طريق الـ API فقط)، وهاد الأسلوب أبسط وما بيحتاج أي
  إعداد إضافي بـ Supabase، وبيوصل لنفس الإحساس بالفورية.
- رسائل المدرب/الأدمن بتنعرض بشكل مميز (🏫 + لون ذهبي) عشان تنفصل بصريًا عن رسائل الطلاب.

## الملفات الجاهزة (انسخيها لمكانها بالـ repo مباشرة، بدون أي تعديل)

```
migration-batch-chat.sql                                          → شغّليه بـ Supabase SQL Editor مرة وحدة

app/api/admin/batches/[id]/chat/route.js                          → GET/POST (عرض/إرسال من طرف الأدمن)
app/api/batches/chat/route.js                                      → GET/POST (عرض/إرسال من طرف الطالب)

app/course/[id]/BatchChatPanel.js                                  → واجهة الطالب (جاهزة، مستقلة)
```

## الملفات اللي محتاجة تعديل يدوي بسيط (تعليمات دقيقة مرفقة)
```
تعليمات-دمج-صفحة-الادمن-12.md    → إضافة زر + نافذة "الدردشة" بلوحة تحكم الدفعات
تعليمات-دمج-صفحة-الطالب-12.md    → إضافة سطرين بس بصفحة الدورة (import + render)
```

## ترتيب التنفيذ المقترح
1. شغّلي `migration-batch-chat.sql` بـ Supabase.
2. انسخي ملفات الـ `app/api/...` والـ `BatchChatPanel.js` لمكانها بالضبط بالـ repo
   (نفس المسارات الموجودة بالأعلى).
3. طبّقي تعليمات `تعليمات-دمج-صفحة-الطالب-12.md` (سطرين بس).
4. طبّقي تعليمات `تعليمات-دمج-صفحة-الادمن-12.md` (4 أجزاء صغيرة بنفس مكان مكتبة الملفات).
5. اعملي commit وpush متل العادة، وراجعي Changes tab بـ GitHub Desktop قبل ما تضغطي Commit
   (تأكدي إنه بس ملفات هاي المرحلة ظاهرة).

## ملاحظة صغيرة
الرسائل ما إلها حد أقصى بالعدد المعروض (بيجيب آخر 50 عند الطالب وآخر 200 عند الأدمن)،
وما في حذف أو تعديل رسالة بعد إرسالها بهاي النسخة — لو حبيتي هاي الميزة لاحقًا
(حذف رسالة من المدرب مثلًا) قوليلي ونضيفها كتحسين صغير منفصل.

بعد ما تخلصي وتتأكدي إنه كل شي شغال، قوليلي. حسب الخطة الأصلية بقي مرحلتين
(13 — الشهادات، و14 — التقويم)؛ قوليلي إذا بدك نكمل عليهم ولا هاي كانت آخر مرحلة
بدك ياها هلأ.
